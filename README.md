# Community Health Intelligence Atlas (CHIA)

CHIA is a research and data-exploration project designed to make county-level community health access and burden information easier to understand and explore.

## Current Status

v0.1 data model and database baseline validated.

- 3,143 U.S. counties
- 59,717 raw observations
- 9,429 normalized measures
- 12,572 validated dimension scores
- Primary Care, Dental, and Mental Health access scores
- MUA/P geographic coverage
- Composite score not yet populated

## County Explorer

The next implementation phase is the County Explorer: an interactive county-level map and profile experience built on the validated v0.1 data model.

## Documentation

Project methodology, data sources, principles, and the implementation-aligned v0.1 data-model specification are maintained in the project documentation.

## Status

Research / development — not yet a public production application.
