# Community Health Intelligence Atlas (CHIA)

# Data Sources

## Purpose

This document catalogs every dataset used by CHIA, including its source, purpose, geographic level, update frequency, and intended use.

---

---

# Data Requirements

Each dataset should include:

* Official source
* Publication date
* Version
* Download location
* License or terms of use
* Geographic coverage
* Update frequency
* Data quality notes

---

# Source Selection Criteria

CHIA will prioritize:

1. Official government sources
2. Peer-reviewed public datasets
3. National coverage
4. Regularly updated datasets
5. Transparent methodologies

---

# Version 1 Core Datasets

Version 1 requires only:

* CDC PLACES
* CDC WONDER
* American Community Survey
* Decennial Census
* HRSA

All other datasets are optional future enhancements.

---

# Data Governance

Every dataset used in CHIA must be documented, versioned, and traceable to its original source. No undocumented or proprietary datasets will be included in Version 1.
